We don't write the rule.

Finding the best groundrule for Le Petit Renard means searching a vast space of possible rules. We hand that search to an autonomous agent: it proposes, tests, and keeps what works — on its own. Below: the loop, and the ideas that make it go further.

The autoresearch loop

We don't hand-write the groundrule. An agent runs an autoresearch loop: read what's been tried, propose a rule, test it on every night, score it, keep it only if it beats the best — then go again, on its own. It's the agentic setup Andrej Karpathy points to as where AI is heading.

Two roles, split clean. The agent owns the loop and runs it autonomously. We supervise from outside: set the levers — patience, model, library — curate the inspiration, and decide when to pivot or start a fresh run.

Each round keeps only what beats the best so far, and builds the next groundrule on it.

Pivoting on patience

Left to only refine its current idea, the agent risks polishing itself into a corner. So we give it a patience — how many rounds it may go without beating its best. Spend them, and the agent must pivot: drop the current line and propose a genuinely different groundrule, every dead end already in front of it.

If pivots stop paying off too — a few in a row with no new best — a harder breakout forces a wider jump. A simple guard against the two ways a search fails: rabbit-holes, and converging too early. It's the part of the loop we lean on most.

Start patient, then close the window. A wide patience — 10+ discarded candidates — suits early, exploratory strokes. Once you're grinding percentage points, a smaller window forces faster pivots.

Each line refines until patience runs out, then pivots; the best-so-far steps down to the champion. Lower is better.

Runs that build on runs

A search needn't be one fixed run. Each new run inherits the champion — the best groundrule so far — and climbs from there, while you change everything around it: the iterations, the model, the patience, the library.

So a search becomes deliberate chapters: a patient run on a strong model to stake out territory, a tighter one to grind detail, a fresh model or library to break a plateau — each standing on the last.

Everything's a dial except the floor. A run can change the model, patience, library, or length — but it always builds on the standing champion, so the bar only moves up.

The library — inspiration, by hand

The library is an optional, human-written input: notes, ideas, framings, even a personality handed to the agent before it thinks. It doesn't fix the answer — it shapes the mental frame the agent searches from.

It's where a person's taste enters an otherwise autonomous loop — a small act of curation that can send the search somewhere it would never have wandered.

Different personalities, different science. Giving the agent different personas produced markedly different approaches to the same problem — a space we think deserves far more exploration.

Run it on your own hardware

The loop talks to any OpenAI-compatible endpoint, so the proposing model can be a local one — LM Studio, or anything serving the same API. Point it at your own hardware and the search runs unmetered: no rate limits, no quota walls, no getting blocked mid-run. Leave a patient search going overnight without watching a bill.
